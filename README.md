# สมุดภารกิจครูซอส (Teacher Quest)

ปฏิทินส่วนตัวของครู นัดหมาย ภารกิจ การประชุม และนับวันเรียน Day 1–200
พัฒนาโดย ครูซอสสอนสังคม

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งระบบ |
| `js/firebase-config.js` | ค่าเชื่อมต่อ Firebase และอีเมลที่อนุญาต |
| `js/firebase-bridge.js` | ตัวเชื่อมระหว่างหน้าเว็บกับ Firestore / Storage / การล็อกอิน |
| `fonts/` | ฟอนต์ TH SarabunPSK สำหรับสร้างเอกสาร Word / PDF |
| `img/` | ภาพหน้าปก โลโก้ และไอคอนแอป |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล (คัดลอกไปวางใน Firebase) |
| `storage.rules` | กฎความปลอดภัยของที่เก็บไฟล์ (คัดลอกไปวางใน Firebase) |
| `cors.json` | ตั้งค่าให้พรีวิว PDF จาก Storage ได้ |
| `manifest.webmanifest` | ให้เพิ่มลงหน้าจอโฮมแบบแอปได้ |
| `vercel.json` | ตั้งค่าแคชไฟล์บน Vercel |

## การเก็บไฟล์
- ไฟล์ไม่เกิน 700 KB (รูปถ่ายเอกสาร ลายมือ PDF ขนาดเล็ก) เก็บใน Firestore ใช้ได้ทันทีโดยไม่ต้องเปิด Storage
- ไฟล์ใหญ่กว่า 700 KB ต้องเปิด Firebase Storage (แพ็กเกจ Blaze)
